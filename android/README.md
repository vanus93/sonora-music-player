# Sonora Native Android

Versi native Android ringan menggunakan Kotlin dan API bawaan Android. Tidak memakai npm atau backend.

## Membuka dan build

1. Buka folder `android` dengan Android Studio.
2. Tunggu Gradle sync selesai.
3. Hubungkan HP dengan USB debugging atau gunakan emulator.
4. Tekan **Run** untuk memasang aplikasi.
5. Untuk APK: **Build > Build App Bundle(s) / APK(s) > Build APK(s)**.

Fitur: pilih file audio lokal, play/pause, seek, volume, equalizer band bawaan Android, dan sleep timer 15/30/60 menit.
